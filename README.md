# ImageToAsset - Halftone Sticker & Asset Studio

Інтерактивна веб-студія для виділення об'єктів на будь-яких фотографіях та їхньої трансформації у презентаційні асети в стилі Halftone / Newsprint / Color Halftone / Paper Halftone з автентичним рваним контуром паперової наклейки (Torn Paper Deckle Edge) та об'ємною 3D тінню на прозорому фоні.

## Особливості та можливості

### 1. Автентичні графічні режими Halftone (Сітка 2x2)
- **Точне півтонове растрування**: регулярна крапкова сітка (Halftone Dot Matrix) під кутом 45° з неперервним динамічним радіусом крапок від яскравості.
- **Чотири спеціалізовані тональні режими**:
  - **Фото-растр (Dots)** — класичний газетний друк 45° з плавним тональним діапазоном, попіксельною деталізацією та безшовним перекриттям крапок у тінях.
  - **Колір + Растр (Color Halftone)** — збереження оригінальних насичених кольорів фотографії з текстурою газетного півтонового растру.
  - **Графічний растр (Graphic Dots)** — чіткі розділені цятки для логотипів, артів, тексту та векторної графіки на білому папері.
  - **Паперовий растр (Paper Halftone)** — неперервний фото-растр на базі Photo Halftone з перекриттям тіней та попіксельною градацією, надрукований безпосередньо на фактурну паперову підкладку наклейки (з білим шовкотрафаретним друком на темних фонах).
- **Тонке регулювання**: інтерактивні повзунки контрастності (Smart S-Curve Contrast) та масштабу крапок растру.

### 2. Генератор рваного паперового краю (Torn Paper Deckle Edge)
- **Точний алгоритм 8SED**: миттєвий розрахунок евклідової відстані від контуру виділеного об'єкта.
- **Фрактальний шум (fBM / Simplex Noise)**: фізичне моделювання природного рваного паперу та целюлозних волокон по периметру.
- **Пом'ята текстура паперу (Crumpled Paper)**: реалістичні діагональні заломи з рельєфним світлотіньовим моделюванням.
- **Стилізований вибір кольору підкладки**:
  - Готові палітри: чистий білий, вінтажний кремовий (#f6f0db), світло-бежевий пергамент (#eee6d3), нейтральний сірий (#d8d8d8) та темний графіт (#1a1a1a).
  - Інтерактивна 2D-дошка спектра та насиченості для вибору довільного кольору.
  - Підтримка ручного введення HEX-коду.
  - Системна піпетка EyeDropper API для точного вибору кольору з будь-якої точки екрана.
- **М'яка об'ємна 3D тінь**: регулювання глибини, зміщення та розмиття (shadowBlur) для створення ефекту наклейки, що ширяє над поверхнею.
- **Зовнішні поля (Buffer Padding)**: можливість створення стилізованої рваної обводки навколо прямокутних фотографій без видалення фону.

### 3. Гібридні інструменти виділення та згладжування контуру
- **Розумне ласо (W)**: інтерактивне виділення контуру з бар'єром першого зіткнення (First-Hit Edge Barrier) та бар'єром глибини для захисту деталей (Depth Fence 28px).
- **Зниження шуму та усунення артефактів обрізання**:
  - 3x3 біноміально-гаусова пре-фільтрація яскравості перед розрахунком градієнтів Собеля для нейтралізації цифрового шуму матриці камери та JPEG-артефактів.
  - Автоматичний компонентний BFS-аналіз: усунення ізольованих острівців шуму площею менше 80 пікселів та заливка замкнених внутрішніх мікропорожнин.
  - Роздільне субпіксельне згладжування контурів (радіус 2.5px): усунення сходинкового аліасингу та формування органічних, гладких ліній обрізання.
- **Кнопка «Згладити та очистити маску»**: швидка оптимізація в 1 клік на панелі інструментів для згладжування масок, створених будь-яким інструментом (з підтримкою Ctrl+Z / Ctrl+Y).
- **Пензель маски (B) та Ластик (E)**: миттєве малювання з плавним відображенням і курсором точного радіуса.
- **Виділення прямокутником (M) та Довільне ласо (L)**: швидка ізоляція об'єкта (Shift для додавання до виділення, Alt для віднімання).
- **Швидкі операції**: Виділити все, Інвертувати маску, Очистити все.

### 4. Високопродуктивний графічний пайплайн 60 FPS
- **Кешування альфа-геометрії паперу (`cachedAlphaField`)**: при зміні кольору підкладки оновлення відмальовується за 0.8-1.2 мс замість 15 мс завдяки повторному використанню розрахованого поля відстаней та шуму.
- **Офлайн-кешування об'ємної тіні (`cachedShadowCanvas`)**: важке гаусове розмиття (CPU blur 50px) кешується на окремому полотні з вирізанням силуету, накладаючись через апаратний `drawImage` за 0.03 мс замість 45 мс.
- **Тротлінг вибору кольору**: синхронізація подій `onInput` через `requestAnimationFrame` для плавної роботи інтерактивного колор пікера без затримок.
- **Пакетний GPU-композитинг**: об'єднання оновлень шарів полотна в один спільний кадр на частоті монітора (VSync).
- **32-бітний прямий запис у піксельний буфер** (`Uint32Array`) та O(1) таблиці підстановки контрасту (LUT).

### 5. Інтернаціоналізація, експорт та інтеграція
- **Повна двомовність (UA / EN)**: миттєве перемикання локалі без перезавантаження сторінки.
- **Копіювання PNG (Ctrl + C)**: копіювання прозорого вирізаного PNG-асету в буфер обміну для вставки в PowerPoint, Keynote, Figma, Canva, Telegram або Photoshop.
- **Експорт в 1 клік**: автоматичне кадрування за межами наклейки зі збереженням обводки та тіні на прозорому фоні.
- **Вставка з буфера (Ctrl + V)** та підтримка Drag & Drop зображень (PNG, JPG, WebP, прозорий фон).
- **Налаштування фону полотна**: темна шахова сітка, світла сітка, суцільний чорний або білий фон.
- **Адаптивний мобільний інтерфейс**: оптимізація під сенсорні екрани смартфонів і планшетів, плаваючий док інструментів та висувна шторка налаштувань.
- **PWA (Progressive Web App)**: підтримка встановлення як автономного додатку з векторним favicon та маніфестом.

## Гарячі клавіші

| Клавіша | Дія |
| :--- | :--- |
| Ctrl + V | Вставити фото з буфера обміну |
| Ctrl + C | Скопіювати прозорий PNG асет у буфер обміну |
| Ctrl + Z / Ctrl + Y | Скасувати / Повторити дію з маскою |
| Ctrl + Shift + Z | Повторити дію з маскою |
| Space + Drag / H | Панорамування робочої області (Pan) |
| Колесо миші | Плавний центрований зум сцени |
| [ / ] | Зменшити / Збільшити радіус пензля |
| W | Розумне ласо (Smart Lasso) |
| B / E | Пензель (Brush) / Ластик (Eraser) |
| M / L | Прямокутне виділення / Довільне ласо |

## Швидкий запуск

```bash
# 1. Клонування репозиторію
git clone https://github.com/SeriySpray/ImageToAsset.git
cd ImageToAsset

# 2. Встановлення залежностей
npm install

# 3. Запуск локального сервера розробки
npm run dev
```

Додаток відкриється за адресою: http://localhost:3000

## Технологічний стек

- **Frontend**: React 19, TypeScript, Vite
- **UI & Стилізація**: Tailwind CSS v4, Lucide Icons, шрифтова гарнітура JetBrains Mono
- **Графічний рушій**: HTML5 Canvas 2D API, Euclidean Distance Transform (8SED), Simplex Noise & fBM, гаусова фільтрація
- **Архітектура**: 32-бітний растровий скрин, O(1) таблиці підстановки (LUT), кешування альфа-геометрії та тіней, rAF-композитинг, субтрактивна ізоляція
