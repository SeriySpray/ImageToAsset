# ImageToAsset - Halftone Sticker & Asset Studio

> Інтерактивна студія для перетворення будь-яких зображень та фотографій у високоякісні презентаційні монохромні асети в стилі Halftone / Newsprint / Engraving з автентичним рваним контуром паперової наклейки (Torn Paper Edge) на прозорому фоні.

---

## Особливості та можливості

- **Автентичний графічний стиль Halftone**:
  - Точне півтонове растрування регулярною крапковою сіткою (Halftone Dot Matrix) під кутом 45° з динамічним радіусом крапок від яскравості.
  - Підтримка альтернативних графічних раструвань: перехресна сітка (`crosshatch`), штрихування (`lines`), ретро-гравюра (`engraving`) та дитеринг за алгоритмом Atkinson (`dither`).
  - Тонке калібрування контрасту, рівнів чорного та білого, інверсії (негатив для темних слайдів).

- **Генератор рваного паперового краю (Torn Paper Deckle Edge)**:
  - Точний $O(N)$ евклідовий розрахунок дистанції від контуру виділеного об'єкта.
  - Фрактальний шум (fBM / Simplex Noise) для моделювання природного рваного паперу та волокон по периметру.
  - Підкладка з делікатною мікротекстурою та підтримкою відтінків паперу.

- **Гібридні інструменти виділення та сегментації**:
  - Розумне авто-виділення об'єктів (`Smart Auto-Cutout`).
  - Прямокутне виділення (`Box Select`).
  - Довільне (`Freehand Lasso`) та полігональне (`Polygon Lasso`) ласо.
  - Малярний пензель (`Mask Brush`) та ластик (`Eraser`) з налаштуванням радіуса.
  - Чарівна паличка (`Magic Wand`) з регулюванням порогу чутливості.

- **Миттєвий експорт для презентацій**:
  - Кнопка швидкого копіювання прозорого PNG у буфер обміну (`Ctrl + C` / `Copy PNG`) для миттєвої вставки в PowerPoint, Keynote, Figma або Canva.
  - Експорт у високій роздільній здатності (1x, 2x Retina, 4x Ultra HD).
  - Підтримка швидкої вставки зображення з буфера обміну (`Ctrl + V`).

---

## Швидкий запуск

```bash
# 1. Встановлення залежностей
npm install

# 2. Запуск локального сервера розробки
npm run dev
```

Додаток відкриється за адресою: `http://localhost:3000`

## Гарячі клавіші

| Клавіша | Дія |
| :--- | :--- |
| `Ctrl + V` | Вставити будь-яке фото з буфера обміну |
| `Ctrl + C` | Скопіювати готовий PNG асет у буфер обміну |
| `Ctrl + Z` / `Ctrl + Y` | Скасувати / Повторити дію з маскою |
| `Space + Drag` / `H` | Панорамування робочої області (Pan) |
| `Колесо миші` | Плавний зум від курсора |
| `[` / `]` | Зменшити / Збільшити радіус пензля |
| `B` / `E` | Пензель (Brush) / Ластик (Eraser) |
| `A` / `M` / `L` / `P` / `W` | Авто-виділення / Прямокутник / Ласо / Полігон / Чарівна паличка |
